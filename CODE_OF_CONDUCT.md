# Code of Conduct

Mingle follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not welcome in issues, pull requests or anywhere else the project lives.

To report behavior that breaks this code, contact the maintainer [@earayu](https://github.com/earayu) privately. Reports are kept confidential.
